# Portfolio Site

A static portfolio built with HTML, CSS, and JavaScript. It includes filterable project cards, two detailed technical case studies, responsive layouts, keyboard focus states, reduced-motion support, metadata, and a sitemap. There is no build step or third-party runtime dependency.

## Preview

Open `index.html` in a browser, or start a local server to test links between pages. No build step is required.

For a simple local server:

```bash
python -m http.server 8000
# Visit http://localhost:8000
```

## Publish to GitHub Pages

The existing repository is published through GitHub Pages at <https://jaykrukar.github.io/portfolio-site/>. Changes should be verified locally and then merged to `main`; confirm the Pages deployment and public site after each content or navigation change.

## Accuracy and privacy

The content describes education, research, AI tasking, and emergency medical work at a high level. The newer linked repos are AI-assisted learning projects, not evidence of years of professional engineering. BioSignal Lab uses synthetic signals only. Do not add protected patient information, client data, proprietary instructions, or confidential contractor task content.
