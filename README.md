# Portfolio Site

A small responsive, dependency-free portfolio page for Jay's public AI evaluation, ML, and Python projects. Features an accessible mobile layout, keyboard focus states, and project filters.

## Preview

Open `index.html` in a browser. No build step required.

For a simple local server:

```bash
python -m http.server 8000
# Visit http://localhost:8000
```

## Publish to GitHub Pages

1. Create a public repo named `portfolio-site` and upload these files.
2. The account name is already set to `jaykrukar`. Verify the existing tracker link; the other project links lead to the public source repositories.
3. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.
4. Your site should appear at `https://jaykrukar.github.io/portfolio-site/` once Pages deploys successfully.

## Accuracy and privacy

The content describes actual education, research, AI tasking, and emergency medical work at a high level. The linked repos are portfolio prototypes prepared with AI assistance, not evidence of years of past technical work. Do not add protected patient information, client data, proprietary instructions, or confidential contractor task content.
