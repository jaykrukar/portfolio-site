PRODUCT / DEVELOPER TOOLING

Coding Evaluation Task Kit

A practical, downloadable workflow for creating small Python coding tasks: write the contract, build an external verifier, check a reference and starter, then hand the package to a human reviewer.

Python 3.10+pytestMIT + CC BY 4.0Open-source learning project

Scope: The included audit checks package structure and known solution outcomes. It does not judge fairness, human solvability, test completeness, benchmark value, or security.

01 / USER PROBLEM

A prompt and a passing reference are not enough.

A task author needs to know whether the brief, tests, and example implementations agree. The kit turns those checks into a repeatable local workflow while leaving subjective judgments with a human reviewer.

02 / WHAT'S INCLUDED

A working tool and reusable materials.

Task scaffolding

repoeval init creates a task brief, manifest, external tests, starter implementation, and passing reference without overwriting an existing destination.

Known-outcome audit

repoeval audit runs the included verifier against the reference and starter, then emits a JSON or human-readable preflight report.

Review templates

The bundle includes an editable task brief, test matrix, verifier review checklist, and evidence-based manual scorecard.

Worked example

The tag-normalization example documents the contract and includes 18 test cases covering normal input, boundaries, punctuation, whitespace, and type errors.

03 / VERIFIED RUN

The included example passes the intended preflight.

On the checked build, the reference implementation passed all 18 cases. The starter was rejected on 10 of 18 cases. The full repository suite passed 21 tests, the generated ZIP passed its archive integrity check, and an extracted copy built and installed as a wheel before its installed CLI created and audited a fresh task.

04 / LIMITS AND DISTRIBUTION

The preflight is deliberately narrow.

  • Passing proves only that this reference passes the included tests and the included starter does not.
  • A syntax error or setup issue can make a starter fail without showing that the verifier catches the intended behavior; inspect the failures.
  • The runner executes Python and pytest. It is not a security sandbox; a timeout does not block filesystem, network, or resource access.
  • The guide and blank templates use CC BY 4.0; source and worked code use MIT. License notices are included in the bundle.
  • The bundle is an open-source product experiment. No checkout, paid listing, customer, or sales results are represented here.

The curated product ZIP is built deterministically with python tools/build_authoring_kit.py. The repository also includes a draft listing and lightweight market notes; no price or demand claim is made on this site.
